# 人生重启系统 🧠

> 通过 10 次结构化心理引导，重新理解自己的生活、目标和行动方式。

这是一个供 Clawdbot 使用的中文人生复盘技能。主题文案提供诊断框架和问题素材；AI 应结合已保存的上下文逐阶段引导、保存原始回答、总结并请用户审核暂定分析，再继续提出不重复的下一步问题。

## 10 次心理重启

| 次数 | 主题 | 你将探索什么 |
|---|---|---|
| 1 | 反愿景设计师 | 如果什么都不改变，你正在走向怎样的人生 |
| 2 | 隐藏目标解码器 | 你的行为实际上在追求什么 |
| 3 | 身份建构追踪器 | 限制性信念从哪里形成 |
| 4 | 生活方式—结果审计师 | 当前生活是否能产生你想要的结果 |
| 5 | 认知失调引擎 | 改变所需要的真实张力 |
| 6 | 目标反馈调试器 | 目标追求循环究竟在哪一环失灵 |
| 7 | 自我阶段导航员 | 你处于什么发展阶段，下一步需要什么 |
| 8 | 人生游戏架构师 | 如何为人生设计任务、规则、风险和奖励 |
| 9 | 条件反射挖掘者 | 哪些信念是继承来的，哪些是你主动选择的 |
| 10 | 一日重启设计师 | 一套可以在一天内执行的个人重启方案 |

## 使用命令

```text
/life              开始或继续中文流程
/life status       查看进度
/life session 3    进入第 3 次主题
/life reset        清除进度并重新开始
```

首次测试或希望从头开始时，先执行 `/life reset`；`/life` 会读取已有的 `state.json` 并从上次进度继续。

也可以使用中文语言命令：

```bash
bash scripts/handler.sh start zh "$WORKSPACE"
bash scripts/handler.sh status "$WORKSPACE"
bash scripts/export.sh "$WORKSPACE"
```

英文和俄文仍然保留兼容：

```text
/life en
/life ru
```

## 工作流程

1. 第一次执行时，系统创建 `state.json` 并显示介绍。
2. 每次只引导当前阶段，并检查此前回答，跳过已充分回答的问题。
3. 用户回答后，先执行 `save` 保存原文；AI 再提供区分事实、暂定解释和不确定性的阶段小结，请用户审核后记录到 `insights.md`。
4. 根据用户确认或修正，提出一个针对未解决信息缺口、且与前面问题不同的下一阶段问题。
5. 完成一个主题后，系统会将阶段回答摘要写入 `insights.md`；这类自动摘要是原文摘录，不等同于 AI 的综合诊断。
6. 完成第 10 次主题后，系统自动生成 `final-document.md`，并返回报告路径；`scripts/export.sh` 仍可用于手动重新生成。

## 用户数据

数据默认保存在：

```text
$WORKSPACE/memory/life-architect/
```

主要文件：

- `state.json`：当前语言、主题、阶段和完成状态
- `session-01.md` 至 `session-10.md`：每次主题的回答
- `insights.md`：每完成一个主题后自动追加的阶段洞察
- `final-document.md`：完成全部 10 次主题后自动生成的完整复盘文档，包含已保存的主题回答与洞察

## 中文文案

中文文案位于 [references/sessions/zh/](references/sessions/zh/)。脚本默认使用 `zh`，但不会删除或覆盖英文、俄文版本。

## 心理安全提示

这不是心理治疗，也不能替代医生或心理咨询师。如果某个问题引发强烈痛苦、创伤反应或自伤想法，请立即暂停，优先联系可信任的人和当地专业支持。任何问题都可以跳过，不需要强迫自己回答。

## 依赖

- Clawdbot 或兼容的技能运行器
- Bash 4.0+
- `jq`

在 Windows 的 Git Bash 中不需要额外安装 `flock`：脚本会自动使用目录锁完成并发保护。
